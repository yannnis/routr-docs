Checks one email address and returns a standard verdict.
It does not send a message and it does not prove the person reads the mailbox.

`POST /v1/email/validate`

MCP tool `email_validate`. CLI `routr email validate`.

Charge rule: `sum`. A cached result costs nothing. This version does not serve cached results.

Worst-case credits: smart 7 · cheapest 7 · pinned 7.

## Verdicts

| Verdict | Meaning | Conclusive |
| --- | --- | --- |
| `catch_all` | Domain accepts every address, so the mailbox is unproven. | No |
| `deliverable` | Mailbox accepts mail. | Yes |
| `undeliverable` | Mailbox rejects mail. | Yes |
| `unknown` | No vendor could decide. | No |

## Example

`{"email":"jane@example.com"}` returns `deliverable`.
